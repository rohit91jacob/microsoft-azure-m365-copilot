# Data licence and attribution

The **code** in this repository is MIT ([LICENSE](LICENSE)). The **data** the pipeline reads
belongs to its publishers. None of it is committed to this repository: every run downloads it
from the public endpoints below, at runtime, into a local data directory that `.gitignore`
excludes.

| Source | Publisher | Terms | Committed here? | What the results site shows |
|---|---|---|---|---|
| [Azure Retail Prices API](https://learn.microsoft.com/rest/api/cost-management/retail-prices/azure-retail-prices) (`prices.azure.com/api/retail/prices`) | Microsoft | [Microsoft APIs Terms of Use](https://learn.microsoft.com/legal/microsoft-apis/terms-of-use); unauthenticated public API | No | Aggregates (change counts, medians, region price indices) and short top-N tables of list prices, with attribution |
| [Microsoft 365 roadmap](https://www.microsoft.com/microsoft-365/roadmap) JSON feed (`www.microsoft.com/releasecommunications/api/v1/m365`) and RSS (`.../api/v2/m365/rss`) | Microsoft | [Microsoft Terms of Use](https://www.microsoft.com/legal/terms-of-use) (content is © Microsoft) | No | Counts by product, status and month; feature **IDs** linking back to the official roadmap. Feature titles and descriptions are not republished |
| [GitHub REST API](https://docs.github.com/rest) for public `microsoft/*` repositories | GitHub / repository owners | [GitHub Terms of Service](https://docs.github.com/site-policy/github-terms/github-terms-of-service) (API use, incl. rate limits) | No | Repository-level counts (stars, weekly commits, merged PRs, release cadence). No personal data: author logins, names, emails and PR text are dropped at extraction; only "is the author a bot" is kept |
| [Internet Archive Wayback Machine](https://web.archive.org/) captures of the two Microsoft endpoints above (CDX API + raw replays) | Internet Archive (captures of Microsoft content) | [Internet Archive Terms of Use](https://archive.org/about/terms.php); the captured content stays under the Microsoft terms above | No | Used only as history for the same aggregates |
| Azure pricing-calculator data (`azure.microsoft.com/api/.../calculator`), npm registry, PyPI, code.visualstudio.com/updates | Microsoft, npm Inc., PSF | Each site's terms | No | Only used by `scripts/verify_published.py` to reconcile results; summarised in [docs/verification.md](docs/verification.md) |

## What *is* committed

| Path | What it is | Licence |
|---|---|---|
| `tests/fixtures/http/**` | **Simulated** API responses generated by `scripts/make_fixtures.py` (seed `azm365-fixtures-v1`): the *shapes* of the four APIs filled with deterministic fake values. Roadmap titles start with `[SIMULATED]`; prices and counts are pseudo-random. Not real Microsoft, Azure or GitHub data. | MIT (own work) |
| `dbt/seeds/region_exclusions.csv`, `dbt/seeds/roadmap_product_aliases.csv` | Hand-maintained reference lists (region names and product-tag renames) | MIT (own work; facts) |

Why simulated fixtures rather than small real samples: none of the Microsoft terms above grant
a licence to redistribute the API responses, so the test fixtures are generated instead, and
every pipeline run on them is labelled `is_synthetic = true` from bronze to the results site
(which then shows a "SIMULATED DATA" banner).
